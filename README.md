# NASSER PDF

أداة مجانية لتحويل الملفات إلى PDF، تحرير PDF، وإنشاء رموز QR — بدون تسجيل دخول أو لوحة تحكم.

## الأدوات

- **Word → PDF** و **PDF → Word**
- **Excel → PDF** و **PDF → Excel**
- **صور (PNG/JPG) → PDF** و **PDF → صور**
- **PDF Editor**: دمج، تقسيم، ترتيب/تدوير/حذف صفحات، علامة مائية
- **تحرير PDF مرئي**: إضافة نص، صور، أشكال، رسم حر، تظليل، إخفاء، توقيع
- **استخراج نص** من PDF
- **تعبئة نماذج PDF**
- **ضغط PDF**
- **QR Code**: روابط، نصوص، بريد إلكتروني، رقم هاتف، شبكات واي فاي

## الخصوصية

أغلب الأدوات تعمل بالكامل داخل متصفحك — ملفاتك ما تُرفع لأي خادم إطلاقاً. الأدوات اللي تحتاج
معالجة خارجية (مثل تحويل Word/Excel) تُعالج مؤقتاً فقط أثناء التحويل، ثم تُحذف فوراً ولا تُحفظ.
